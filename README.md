# 트러스 실습실

이 폴더는 [kiser232/truss-lab](https://github.com/kiser232/truss-lab)을 수업용으로 확장한 복사본입니다. 계산기에 공간 트러스와 절점별 풀이를 더했고, 실습 마지막에 책 하중 경진을 넣었습니다. 원본 페이지는 바꾸지 않습니다.

건축공학과 학생을 위한 트러스 교육 웹앱입니다. 처음 열면 트러스 계산기, 실습, 퀴즈 중 하나를 고르고, 그 화면으로 들어갑니다.

격자 한 칸은 1m이고 힘의 단위는 N입니다. 교육용 모형 스케일이라 실제 구조물 하중과는 크기가 다릅니다. 부재 단면이 정해져 있어 **허용축력(N)** 과 비교합니다. 실무에서는 응력 σ = N / A 를 허용응력과 비교합니다.

## 화면

1. **트러스 계산기** — 격자 또는 좌표로 절점을 놓고 부재를 잇습니다. 평면과 공간 모드가 있습니다. 공간에서는 바닥 격자(x, z)에 절점을 놓고 높이 y를 정하며, 빈 곳을 끌면 시점이 회전합니다. 해가 나오면 절점별 계산 과정을 넘기며 볼 수 있습니다. 평면 정정 조건은 `m + r = 2j`, 공간은 `m + r = 3j` 입니다.
2. **실습** — 단계마다 예산이 있습니다. 1–7단계는 기존의 계곡·도로·절벽 미션입니다. 8단계는 책 하중 경진으로, 종이·스파게티·수수깡만 쓰고 점수는 견딘 책 무게 ÷ 재료비입니다.
3. **퀴즈** — 변형 문제는 단면법, 영부재, 압축재 개수를 묻고, 사진 문제는 실제 트러스 형식을 묻습니다. 힌트는 원할 때 열고, 풀이는 답을 확인한 뒤에 나옵니다. 연습 퀴즈는 재료 분류와 인장·압축 부재를 무작위로 냅니다.

인장(+)은 부재가 절점을 당기는 힘, 압축(−)은 미는 힘입니다. 평면 트러스의 정정 조건은 `m + r = 2j` 입니다.

## 로컬 실행

```bash
npm install
npm test
npm run dev
```

정적 사이트로 빌드한 뒤 확인하려면:

```bash
npm run build
npx serve out -l 43123
```

## Docker

```bash
docker build -t truss-lab .
docker run --rm -p 43123:43123 truss-lab
```

## GitHub Pages

`main`에 푸시하면 `.github/workflows/pages.yml`이 `out` 폴더를 GitHub Pages로 배포합니다. 저장소 설정에서 Pages 원본을 **GitHub Actions**로 한 번 지정해야 합니다. 프로젝트 페이지(`username.github.io/저장소이름`)는 빌드할 때 저장소 이름을 base path로 넣습니다. 사용자 페이지(`username.github.io`)는 루트에 배포됩니다.
